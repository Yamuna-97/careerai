# CareerAI Unified Platform

CareerAI is an AI-driven career acceleration platform that provides intelligent resume optimization, live AI mock interview coaching, and smart job discovery.

## 📁 Repository Structure

```
careerai/
├── backend/                  # Backend application services (empty, ready for backend setup)
└── frontend/                 # Frontend client application & Stitch AI screens
    ├── shaders/              # WebGL / Canvas shader modules
    │   ├── shader-1.html
    │   └── shader-2.html
    ├── index.html            # Main Landing Page with Interactive WebGL Hero
    ├── landing-static.html   # Alternative Static Landing Page
    ├── login.html            # User Login Screen
    ├── signup.html           # User Registration Screen
    ├── dashboard.html        # Main Platform Dashboard & Metrics Hub
    ├── resume-editor.html    # AI Resume Builder & ATS Optimizer
    ├── interview-session.html# Live AI Mock Interview Session
    ├── interview-evaluation.html # Comprehensive Interview Feedback & Scores
    ├── jobs.html             # Smart Job Discovery & Application Matcher
    └── DESIGN_SYSTEM.md      # Tokens, Color Schemes, Typography & Layout Specs
```

## 🚀 Getting Started

### Frontend
Open [`frontend/index.html`](file:///d:/careerai/frontend/index.html) in any modern web browser or serve using a static file server:

```bash
# Using Node.js http-server / npx serve:
npx serve frontend
```

### Backend
The [`backend/`](file:///d:/careerai/backend) directory is created and ready for your backend framework of choice (Node.js/Express/FastAPI/Django/Go).
